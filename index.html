🎯 Philosophy

🔍 Evidence First

Never guess. Always verify. Read code before debugging. Understand before fixing.

🎯 Minimal Fix

Apply the smallest change that fixes the root cause. Don't rewrite what isn't broken.

✅ Verification Required

Never claim success without proof. Run tests, check build, verify output. Always.
