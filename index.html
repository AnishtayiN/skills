🚀 Installation

Get started in 30 seconds.

1

Clone the repo

Download the skill library to your machine.

2

Run the installer

Interactive menu — pick your agents.

3

Start coding

Your agent now knows 25 professional skills.

# Clone
git clone https://github.com/AnishtayiN/skills.git
cd skills

# Interactive install
./install.sh

# Or install directly
./install.sh --claude
./install.sh --cursor
./install.sh --all

# Uninstall
./install.sh --uninstall claude

# Update
./install.sh --update all
