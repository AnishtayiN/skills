Built around three non-negotiables.

Good agent behavior is a process, not a personality trait.

◈Evidence first

Read the code, inspect the constraints, and attach claims to observable evidence.

◎Minimal change

Fix the root cause with the smallest safe diff. Avoid unrelated cleanup and speculative abstractions.

✓Verify proportionally

Use the checks that match the risk: syntax, focused tests, integration, security, rollback, and more.

Install it where your agent works.

Project-local by default. Existing user instruction files are preserved.

Recommended

Clone, review, and run the installer from the target project.

git clone https://github.com/AnishtayiN/skills.git ~/.local/share/agent-skills cd /path/to/your-project ~/.local/share/agent-skills/install.sh --claude

Validate before installing

The repository includes a dependency and metadata checker.

python3 scripts/validate_skills.py bash -n install.sh ./install.sh --help
